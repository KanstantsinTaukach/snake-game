Snake Game is a classic implementation of the popular Snake arcade game developed in C++. The project demonstrates fundamental game development concepts, 
including game loops, input handling, collision detection, score tracking, and dynamic object management.

Players control a growing snake, collect food to increase their score, and avoid collisions with walls and their own tail. The project focuses on clean code structure, 
object-oriented programming principles, and efficient game logic implementation.

This repository serves as a practical example of C++ programming and core game development mechanics, showcasing problem-solving skills and a solid understanding 
of gameplay systems.
